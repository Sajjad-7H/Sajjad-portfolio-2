# Sajjad Hosen Emon Portfolio

Open `index.html` in a modern browser. The page uses Banna's MIT-licensed animation to draw and type the visible section with 12 colored cursors; later sections build as they enter view while scrolling. Use the button in the build bar or press Escape to reveal the page immediately. The animation respects reduced-motion preferences.

The Banna script is bundled locally at `assets/banna.js`; its MIT license is included at `assets/banna-LICENSE.txt`. The in-page author credit is disabled; the required license attribution remains. Fonts, Devicon icons, and the existing PDF export library load from their configured CDNs.

GitHub Pages deploys automatically from `main` with the workflow in `.github/workflows/pages.yml`.
